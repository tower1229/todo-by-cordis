# Triage Labels

| Canonical role | 项目标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可由 Agent 开始实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予实施 |

使用技能指定的角色对应标签；已存在的同名标签复用，缺失标签在实际需要时创建，不覆盖已有标签描述。ready-for-agent 不表示实现或验收已完成。
